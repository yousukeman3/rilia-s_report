# 魔術体系の読み方

[資料集の入口](../README.md) · [魔術の記事一覧](README.md)

原資料の長い解説を読むための案内。詳しい制約・例外と表現は[魔力](魔力.md)、[魔術](魔術.md)、[錬金術](錬金術.md)本文に残している。以下はその要約であり、新たな理論の追加ではない。

## 魔術が起こるまで

1. **魔力を準備する。** 自分のオド、自然界の魔術元素などを用意し、必要に応じて属性を付与・転換する。
2. **魔力を調律する。** 術者の心身による生体調律と、詠唱・魔法陣などによる外部調律で、現象の雛形である形相（エイドス）を構築する。
3. **体系原理に接続する。** 霊脈を経由して原理楔礎へ接続し、体系原理（プリンシパル）に従って形相を現象へ転換する。

```mermaid
flowchart LR
    A[魔力の準備] --> B[生体調律・外部調律]
    B --> C[形相の構築]
    C --> D[霊脈を経由して原理楔礎へ接続]
    D --> E[体系原理による肯定]
    E --> F[現象化]
```

原理楔礎の例として、神、ローゼ＝フィアス大魔術式盤、世界そのものが挙げられている。術者が使用する体系を理解し、選び取れることが前提となる。出典：[魔術](魔術.md)。

## 第一質料と元素

| 名称 | 原資料での位置づけ |
| --- | --- |
| 第一質料（プリママテリア） | 分化していない純粋な魔力。魔女が「愛」と呼ぶという記述は、魔女の言葉として記される。 |
| マナ | この世界を構成するといわれる第一質料。通常は五大元素のいずれかに変化している。 |
| オド | ソウルラダーが生命力とアストラルから練り上げる、生物の体内の第一質料。 |
| アストラル | 星幽界に満ち、魂の材料となる第一質料。自分自身の在り方を規定する。 |
| アイテール | アイテール界の第一質料。マナとの相性が悪く、この世界の生物には猛毒とされる。 |

四大元素は物理的な物質そのものというより、現象の意味を人が捉えるための枠組みである。アイテール界では、その四大元素が物質そのものになるという違いがある。出典：[魔力](魔力.md)、[アイテール界](../世界観/アイテール界.md)。

| 元素 | 読み | 付与する性質 | 主な説明 |
| --- | --- | --- | --- |
| 土 | ゲー | 乾・冷 | 固体、支えるもの。 |
| 水 | ヒュードル | 湿・冷 | 液体、流動するもの。 |
| 風 | エアル | 湿・暖 | 気体、揮発するもの。 |
| 火 | ピュール | 乾・暖 | 空体、エネルギー、直進という地上の運動。 |
| エーテル | 空とも表記 | 四元質の均衡ある調律、または特定の固有性質 | 天上界の調和。四大元素とは役割が異なる。 |

実エーテルと仮想エーテルは役割・現れ方による区別。仮想エーテルは力のやり取りを説明するために導入された、観測できない仮説上の元素として記載される。

このほか、光・闇の精神元素、固有元素、鏡役質料、例外質料である虚無と錯誤がある。精神元素の光・闇は優劣のある二項対立を構成する説明であり、物理的な光と暗闇に置き換えない。闇の生成特性には本文内で不一致があるため、[要確認事項](../編集管理/要確認事項.md)を参照。

## 術者による違い

魂の大きさ、ソウルラダー、肉体の魔力容量、魔力転換の速度、付与できる特性、生体調律が魔術の質やレパートリーに関わる。魂の枯渇と肉体のオドの枯渇には、それぞれ精神・生命への重大な影響が説明されている。

外部調律は知識に依存し、生体調律は術者の心身に依存する。一般的には両方を併用し、生体調律だけで術式を構築できる場合には無展開発動（ノンスペルキャスト）と呼ぶ。出典：[魔術](魔術.md)。

人物CSVの「魔力貯蔵」「属性転換」と解説本文の「魔力容量」「魔力転換」にはラベルの違いがある。また「愛」「目」「歴史」「行使階梯」「表現」は人物に値が登録されているが、このZIPでは評価基準が揃っていない。数値換算や同一視は行っていない。

## 錬金術

物質と魔力の対応、形相による性質の決定、より善い方向への変化という思想を基礎とする。魔術による錬金術は錬金魔術と呼ぶが、錬金術の実践そのものに魔術適性が必須とはされない。

| 工程 | 段階 | 到達内容 |
| --- | --- | --- |
| 黒化（Nigredo） | 操作論的 | 物理・化学的操作で形相を剥がす／移す。薬師の扱う範囲。 |
| 白化（Albedo） | 魔術論的 | 形相を意図的・安定的に移す。ポーションの作成が到達の証。 |
| 黄化（Citrinitas） | 天体論的 | 形相を変容・調整する。生命創造や不完全エリクシールを含む。 |
| 赤化（Rubedo） | 魔法論的 | 形相そのものを定義する。原資料では実例がなく、未到達とされる。 |

ポーションは飲んだ者の肉体への一時的な変化、エリクシールはさまざまなものへの永続的に善い変化として区別される。不完全な不老不死のエリクシールには、継続服用や体内元素調整の負担がある。出典：[錬金術](錬金術.md)。
