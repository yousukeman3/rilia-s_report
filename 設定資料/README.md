## 資料の読み方

人物の内面・秘密と、来歴欄に書かれた将来の展開を含む、作者向けの資料集です。第一話時点の登場人物が知っている情報とは一致しません。

整理版は原資料の記載をまとめたもので、今回の作業によって新たな設定を追加・確定したものではありません。人物の台詞や伝聞、作中理論の仮説には、そのままの位置づけを残しています。

「本文未記載」は収録ページに本文がないもの、「本文未収録」はCSVに情報があるものの個別本文がZIPにないものです。いずれも名称から内容を補完していません。Notionのテンプレート説明、ダミー、空のページは原資料に保存しています。
